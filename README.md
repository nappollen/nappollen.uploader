## Installation

### Via Package Manager

1. Open the Package Manager window
2. Click the "+" button and select "Add package from git URL..."
3. Enter: `https://github.com/nappollen/uploader.git`

### Via manifest.json

Add the following line to your `Packages/manifest.json`:

```json
"nappollen.uploader": "https://github.com/nappollen/uploader.git"
```
